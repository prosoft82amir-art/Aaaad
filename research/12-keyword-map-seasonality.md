# ۱۲ — نقشه کلیدواژه + رفتار فصلی + داده‌های Autosuggest

## ۱۲.۱) روش استخراج
۳۶+ استعلام زنده از `suggestqueries.google.com/complete/search` با `client=firefox&hl=fa&gl=ir` — یعنی **پیشنهادهای واقعی کاربران ایران در لحظه جستجو** (نه تخمین ابزارها).

## ۱۲.۲) نقشه کلیدواژه بر اساس قصد (Intent)

### قصد خرید/مقایسه محصول (بالاترین ارزش تبدیل)
| خوشه | کلیدواژه‌های اصلی | وضعیت ما |
|---|---|---|
| ضدآفتاب | بهترین ضدآفتاب ایرانی ۱۴۰۵ • ضدآفتاب لافارر رنگی • ضدآفتاب لاروش نی نی سایت • ضدآفتاب برای پوست چرب و جوشدار | ✅ ۱۵ مقاله |
| شامپو | بهترین شامپو برای موهای چرب/خشک • شامپو کافئین سریتا خوبه • شامپو بدون سولفات لافارر | ✅ |
| سرم | بهترین سرم ویتامین C ایرانی • پریم یا لافارر • بهترین سرم رتینول مبتدی | ✅ |
| مرطوب‌کننده | هیدرودرم لاکتات ۱۴ درصد • کرم آبرسان ایرانی | ✅ + مقاله جدید |
| اوره | کرم اوسرین اوره ۱۰ • فرق اوره ۱۰ و ۲۵ | ✅ مقاله جدید |

### قصد اطلاعاتی/آموزشی (بالاترین ارزش ترافیک)
| خوشه | کلیدواژه‌ها | وضعیت |
|---|---|---|
| رتینول | رتینول چیست • عوارض رتینول • طریقه مصرف رتینول | ✅ |
| لک | ترتینوئین برای لک • آزلاسیک اسید برای جای جوش • ترانکسامیک اسید | ✅ |
| تغذیه | تخم مرغ برای مو • بهترین خوراکی برای ریزش مو | ✅ |
| سبک زندگی | روشن کردن طبیعی پوست • مدل موی کم پشت | ✅ |
| روتین | روتین پوست چرب صبح و شب | ⚠️ مقاله هاب نداریم |

### قصد احساسی/تجربه (مالکیت با UGC و بخش نظرات)
```
شامپو ضد شوره سریتا خوبه
سرم ویتامین سی لافارر خوبه
نظرات شامپو بیوکسین
نقد و بررسی کرم ثمین
هیدرودرم لاکتات خوبه
پودر کلاژن نظرات مصرف کنندگان
```
→ **این کوئری‌ها را باید در FAQ هر مقاله با پاسخ صریح مالک شد** (الگوی ثابت مقالات ما).

## ۱۲.۳) تقویم فصلی (بر اساس رفتار جستجوی ایران)

| فصل | کوئری‌های صعودی | مقالات هدف | اقدام |
|---|---|---|---|
| **پاییز (مهر–آبان)** | بهترین ضدآفتاب پاییز • شروع رتینول • خشکی پوست بعد تابستان | ضدآفتاب‌ها، رتینول مبتدی، آبرسان | بروزرسانی + CTA |
| **زمستان (دی–بهمن)** 🔴 پیک | کرم آبرسان خیلی خشک • اوره • کره بدن • لب خشک • روتین زمستانی | اوره، هیدرودرم، لوسیون/کره بدن، ماسک لب | **مقاله جدید «روتین زمستانی» + بروزرسانی ۶ مقاله** |
| **بهار (اردیبهشت–خرداد)** 🔴 پیک | بهترین ضدآفتاب ۱۴۰۵ • SPF • لک بعد آفتاب | ۱۵ مقاله ضدآفتاب | بروزرسانی انبوه تیترها (بدون تغییر اسلاگ) |
| **تابستان** | جوش چربی • ماسک مو • ضدآفتاب ضدآب | ضدجوش، ماسک مو، فیزیکال مای | بروزرسانی |

**نکته فنی:** اسلاگ‌های انگلیسی بدون سال داریم → تغییر سال در تیتر/متا بدون آسیب به رتبه ممکن است. این یک مزیت معماری است.
